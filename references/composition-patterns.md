# Composition Patterns

Choose one structure. Do not mix too many patterns in a single image.

## Structure Types

### Workflow

Use for input -> process -> output, content production, AI workflows, automation chains, and handoffs.

Draw input on one side, a strange low-tech processing object in the middle, and output on the other side. Use orange for the main flow.

### System Slice

Use for sources, filters, databases, renderers, agent internals, or a local piece of a larger system.

Draw only 3-5 essential modules. The expressive white character should operate one critical part, such as a valve, filter, drawer, or lever.

### Before and After

Use for scattered vs organized, manual vs automated, anxious vs stable, invisible vs visible.

Draw the messy state on the left and the calmer state on the right, with the character causing the transformation.

### Character State

Use for creator pain, tool overload, information anxiety, blocked work, or becoming unstuck.

Draw 2-4 small states, each with one short label. Keep it like a sparse sketch, not a comic poster.

### Concept Metaphor

Use for abstract ideas such as trust, leverage, compounding, bottlenecks, attention, context, or judgment.

Draw one strange physical object or small machine. It should feel invented for this article.

### Method Layers

Use for frameworks, capability stacks, system layers, or maturity levels.

Draw hand-built layers, boxes, shelves, trays, or unstable platforms. Avoid a formal pyramid.

### Route Map

Use for journeys, onboarding paths, content funnels, learning paths, and idea-to-launch movement.

Draw one winding path with a few nodes. The character should pull, mark, repair, or walk the path.

### Mini Comic

Use for failure-to-success, a real process, a quick joke, or a use-before/use-after contrast.

Draw 2-4 tiny scenes. Each panel gets one action, not a full explanation.

## Inventing Original Metaphors

Always reinvent the metaphor from the current article.

Use this three-step method:

1. Turn the abstract idea into a physical action: catching, leaking, weighing, folding, routing, sorting, fermenting, jamming, opening, packing, filtering, resurfacing.
2. Turn the structure into a low-tech object: a drawer, pipe, postal slot, odd desk, scale, ladder, sieve, broken machine, box, switchboard, clothesline, crank, trapdoor, or tiny workshop.
3. Make the character perform the action: pulling, carrying, stamping, catching, repairing, pushing, sorting, feeding, weighing, stitching, guarding, or redirecting.

Use only 1-2 main objects. A strange single object is better than a crowded symbolic zoo.

## Originality Rules

Do not reuse a previous composition just because the topic sounds similar. If a prior image used a bridge, try a valve, scale, workshop, drawer, or trapdoor. If a prior image used a route, maybe show a handoff desk or a leaky pipe instead.

Keep the meaning stable, but change the object, action, layout, and the character's job.
